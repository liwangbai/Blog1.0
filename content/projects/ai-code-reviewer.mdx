An automated code review tool that integrates with GitHub to provide first-pass reviews on pull requests.

## How It Works

1. Listens for GitHub webhook events on new PRs
2. Fetches the diff from the GitHub API
3. Sends the diff to an LLM with a structured review prompt
4. Posts the review as inline comments on the PR

## Technical Highlights

- Built a review prompt template that guides the LLM to focus on bugs, security, and style
- Used GitHub Checks API to integrate natively with the PR workflow
- Implemented rate limiting and diff chunking for large PRs
- Built a feedback loop so developers can rate review quality

## Stack

- **Backend**: FastAPI with async handlers
- **Database**: PostgreSQL with SQLAlchemy
- **AI**: OpenAI API with structured prompts
- **CI/CD**: GitHub Actions for deployment
