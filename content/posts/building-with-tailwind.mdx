Tailwind CSS changed how I approach styling. Instead of switching between files, you style directly in your markup.

## Why Utility-First?

Traditional CSS requires naming things:

```css
/* Before: BEM-style naming */
.card { }
.card__title { }
.card__body { }
.card--featured { }
```

With Tailwind, you compose styles inline:

```html
<div class="rounded-lg border bg-white p-6 shadow-sm">
  <h3 class="text-lg font-semibold text-gray-900">Card Title</h3>
  <p class="mt-2 text-gray-600">Card content goes here.</p>
</div>
```

## Responsive Design

Prefix any utility with a breakpoint:

```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  <!-- Cards -->
</div>
```

## Dark Mode

Tailwind's `dark:` variant makes dark mode trivial:

```html
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
  Content adapts automatically.
</div>
```

## Reusable Components

Extract common patterns into components, not CSS classes:

```tsx
function Button({ variant, children }) {
  const base = "px-4 py-2 rounded-lg font-medium";
  const variants = {
    primary: "bg-blue-600 text-white hover:bg-blue-700",
    secondary: "border border-gray-300 hover:bg-gray-100",
  };
  return (
    <button className={`${base} ${variants[variant]}`}>
      {children}
    </button>
  );
}
```

Tailwind shines when paired with a component framework like React — the combination is unbeatable for shipping UI fast.
