A TUI (Terminal User Interface) dashboard built with Rust and ratatui.

## Features

- View and filter open pull requests across repositories
- Manage local task list stored in SQLite
- Quick deployment status checks via CLI
- Keyboard-driven navigation with vim-style keybindings

## Why Rust?

I chose Rust for performance and the ratatui ecosystem. The terminal rendering library is excellent, and the compiled binary starts instantly — important for a CLI tool you use dozens of times per day.

## Status

Archived. This was a fun side project but maintainers found it easier to use the GitHub CLI directly. `gh pr list` covers 90% of the use case.
